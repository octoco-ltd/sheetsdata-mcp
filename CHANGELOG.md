# Changelog

User-facing changes to the `@sheetsdata/mcp` npm package, the Claude
Desktop bundle (`.mcpb`) and the MCP Registry entry. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions
follow [Semantic Versioning](https://semver.org/).

Each release's section becomes its GitHub Release notes (see
[RELEASING.md](RELEASING.md)). Notes for 1.3.2 and earlier are on the
[releases page](https://github.com/octoco-ltd/sheetsdata-mcp/releases).

## [Unreleased]

### Fixed

- **Node.js requirement.** `npx @sheetsdata/mcp` needs Node.js 20.18.1
  or later: the pinned mcp-remote loads undici 7, which fails on
  Node 18 with `File is not defined`. The README said Node 18 was
  enough; it now gives the real minimum, `package.json` declares it in
  `engines` (npm's engine warning on an older Node now names
  `@sheetsdata/mcp`), and the Claude Desktop bundle's manifest
  declares it for Claude Desktop to check.
- **API key whitespace.** `npx @sheetsdata/mcp` now trims the API key
  from `--api-key` and `SHEETSDATA_API_KEY`, as the Claude Desktop
  bundle already did. A key pasted with a trailing newline or space no
  longer produces a malformed `Authorization` header, and a
  whitespace-only key now means "no key": a whitespace-only `--api-key`
  falls back to `SHEETSDATA_API_KEY`, and with neither set the CLI uses
  OAuth.

## [1.4.0] - 2026-10-16

The package still runs the same proxy to the hosted server; this
release brings its listings and install docs up to date with the
server's 14 tools.

### Added

- **Two tools in every listing.** `find_parts` finds parts by numeric
  specs with units (for example `Vin >= 24 V`, `Iout >= 2 A`), package
  or stock, and reports pass, fail or unknown for each constraint with
  its source. `check_bom` checks up to 20 BOM lines for lifecycle,
  stock against quantity, single-distributor sourcing, datasheet status
  and stale prices. The Claude Desktop bundle, `mcp.json` and the
  server card (`.well-known/mcp/server-card.json`) now list all 14
  tools, and a test fails if those lists and the README's drift apart.
- **Prices in the README**, per tool, as charged today, with the free
  start: a new account gets $5 of credit without a card, and searching
  is free.
- **Install steps for more clients**, each checked against the
  client's own documentation on 2026-10-16: ChatGPT, OpenAI Codex,
  GitHub Copilot CLI, Gemini CLI, Google Antigravity, Goose, Roo Code,
  Kiro, JetBrains Junie and AI Assistant, opencode, LM Studio and Warp,
  beside Claude, Claude Code, Cursor, VS Code, Windsurf, Zed, Cline,
  Continue and Amp.
- The MCP Registry entry has a title, website and icons.

### Fixed

- **One-click install links work on GitHub.** GitHub drops `cursor://`
  and `vscode:` links from rendered READMEs, so the Cursor and VS Code
  badges did nothing. They now use the vendors' https install pages,
  and there are links for VS Code Insiders and Kiro too.
- **Zed** signs in with OAuth and takes the URL directly under
  `context_servers` (the README had it under a `settings` key and said
  Zed needed an API key). **Cline** adds the server from its Remote
  Servers screen and signs in; its API-key entry needs
  `"type": "streamableHttp"`, without which Cline assumes SSE.
- **Windsurf** (now Devin Desktop) reads `serverUrl` from
  `~/.config/devin/mcp_config.json`; **Continue** reads
  `.continue/mcpServers/*.yaml` with `type: streamable-http` and the key
  in Continue's secrets; **Claude**'s connectors live under
  Customize → Connectors.

### Changed

- Support and author contact moved to sheetsdata.com addresses.

## [1.3.3] - 2026-10-13

### Fixed

- **`npx @sheetsdata/mcp` runs the mcp-remote version it pins.** The CLI
  used to start the proxy with `npx -y mcp-remote`, which resolves from
  the caller's working directory and ignored the pinned 0.1.38, so the
  proxy floated to whatever version npm resolved. It now runs the copy
  installed with the package, using the same Node binary.
- **Windows.** Starting the proxy no longer fails with `ENOENT`: the CLI
  no longer spawns `npx` without a shell.
- **API key kept off the command line.** With `SHEETSDATA_API_KEY` or
  `--api-key`, the key used to be passed to the proxy as an argument,
  where other local users can read it with `ps`. It now travels in the
  child process's environment, through mcp-remote's `${VAR}` header
  interpolation. The Claude Desktop bundle does the same.
- **Claude Desktop bundle.** The bundle's manifest now passes the
  official MCPB validator. It declared its eight prompts without the
  `text` field the schema requires; the prompts are generated by the
  server, so the manifest now says that (`prompts_generated`) instead
  of listing them. The bundle is packed with the official `mcpb` CLI,
  from a committed lockfile, so its dependencies no longer float
  between builds.
- **One-click install.** The v1.3.2 release had no `.mcpb` attached, so
  the README's download link led to a release without one. Every
  release now carries its bundle.
- The server card (`.well-known/mcp/server-card.json`) lists all 12
  tools, and advertises OAuth with API-key fallback.

### Changed

- Releases are published by CI from the release tag: npm (with
  [provenance](https://docs.npmjs.com/generating-provenance-statements)),
  the MCP Registry and the GitHub Release, in one workflow.
